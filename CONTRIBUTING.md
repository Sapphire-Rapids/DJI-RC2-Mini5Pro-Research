# Contributing

Contributions should add reproducible evidence, correct an existing claim, or make the archive
easier to verify.

For each new result, provide:

- subject and exact public version information;
- one canonical status from [AGENTS.md](AGENTS.md), including `RETRACTED` or `NOT ADMITTED` when
  those are the correct disposition;
- preconditions and route;
- positive controls;
- exact redacted result;
- what the result does not establish;
- source URL/revision or local public document reference;
- whether a state change occurred and whether it was restored.

Do not attach vendor firmware/APKs/libraries, decompiled source, raw private captures, serials,
accounts, tokens, signed licenses, keys, real IDs, telephone numbers, or coordinates. Use synthetic
fixtures and describe raw material by hash and high-level structure only.

Run the checks listed in [AGENTS.md](AGENTS.md) before opening a pull request.
