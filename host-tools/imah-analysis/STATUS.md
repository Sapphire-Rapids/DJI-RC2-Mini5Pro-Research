# Status

- `STATIC`: wrappers and tests are published; the pinned upstream parser is named but not vendored.
- `OBSERVED`: prior local audits verified selected public integrity/signature facts against excluded
  artifacts. Those artifacts and raw reports are not distributed here.
- `NOT ADMITTED`: a `.nonflashable.bin` experiment is intentionally invalid and is never evidence
  of a usable, signed, upgradeable, or flashable package.
- No code in this directory communicates with an aircraft, controller, Assistant service, updater,
  bootloader, or flashing endpoint.
