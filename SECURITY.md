# Security and sensitive research material

Do not report sensitive device or account material in a public issue. Redact serial numbers, UAS
and registration IDs, coordinates, phone numbers, account/session values, tokens, cookies, signed
license data, ADB keys, private URLs, and raw captures.

Do not upload DJI firmware, APKs, extracted partitions, shared libraries, decompiled vendor source,
or temporary patched images to this repository. A hash may be reported without distributing the
file.

For a repository-documentation vulnerability or accidental sensitive-data exposure, contact the
repository owner privately through GitHub before publishing the data.
